# WordBridge 使用指南

WordBridge 是一款結合 AI 技術的 NVDA 附加元件，協助用戶辨識並修正中文同音錯別字。

每次檢查後，WordBridge 會產生校正報告，顯示原文、建議修正的文字，以及相關字詞的解釋。用戶可藉此核對用字，並在校對過程中學習詞彙、累積正確用字的經驗，逐步提升書寫能力。

## 執行文字檢查

要檢查文字有否同音錯別字，請先選取要檢查的內容，然後按下 `NVDA+Alt+O`。檢查期間會播放提示音效。檢查完成後，校正後的文字會自動複製到剪貼簿，方便後續使用。

---

## 檢視校正報告

每次執行文字檢查時，WordBridge 都會產生一份報告，列出所有辨識出的錯別字。每個錯別字都會以可點擊的按鈕顯示；點擊後可查看原文與校正後文字的字詞解釋，幫助用戶在每次校對時學習詞彙、累積正確用字的經驗，提升書寫能力。

若已啟用 **「自動顯示錯別字校正報告」** 選項，報告頁面會在每次檢查後自動開啟。若未啟用，亦可隨時使用 **「顯示校正報告」** 手勢開啟。

## 調整設定

你可透過 `NVDA 功能表 → 偏好設定 → 設定 → WordBridge` 調整以下選項：

- **服務供應商**\
  選擇提供文字校正服務的雲端服務供應商。

- **大型語言模型（LLM）**\
  根據所選的服務供應商，選擇合適的語言模型。

- **校正模式**\
  - *標準模式*：校正結果的讀音會盡量接近原文，適合希望避免聯想到關聯較弱的同音字的用戶。\
  - *輕量模式*：校正結果的讀音可能與原文有較大差異，適合希望在輸入時探索更多同音字聯想的用戶。

- **簡體／繁體中文**\
  指定要處理的文字屬於簡體中文或繁體中文。輸入文字會自動轉換成所選的簡體或繁體形式。

- **個人詞典**\
  提供自訂詞彙清單，以提高專門領域詞彙或專業術語的校正準確度。你可從設定中開啟「編輯辭典」新增詞彙。檢查文字時，WordBridge 會將這些詞彙傳送給 LLM 作參考。

## Coseeing 服務

Coseeing 提供設有使用頻率限制的免費額度，適合短期試用功能。如需大量使用，建議向支援的服務供應商註冊並取得自己的 API 金鑰，以獲得更快速、穩定的服務。

---

## 資料私隱

執行文字檢查時，所選文字會傳送至你設定的 **服務供應商** 處理。使用前請細閱所選服務供應商的私隱政策。
