# WordBridge 使用指南

WordBridge 是一款结合 AI 的 NVDA 附加组件，帮助用户识别并纠正中文同音错别字。

每次检查后，WordBridge 都会生成纠错报告，显示原文、建议修改的文字及相关字词的解释。用户可以借此核对用词，并在校对过程中学习词汇、积累正确用词的经验，逐步提高写作能力。

## 执行文字检查

要检查文字中是否有同音错别字，请先选中要检查的内容，然后按 `NVDA+Alt+O`。检查期间会播放提示音。检查完成后，纠正后的文字会自动复制到剪贴板，方便后续使用。

---

## 查看纠错报告

每次执行文字检查时，WordBridge 都会生成一份报告，列出所有识别出的错别字。每个错别字都以可点击的按钮显示；点击后可查看原文和纠正后文字的字词解释，帮助用户在每次校对时学习词汇、积累正确用词的经验，提高写作能力。

如果启用了 **“自动显示纠错报告”** 选项，报告页面会在每次检查后自动打开。如果没有启用，也可以随时使用 **“显示纠错报告”** 手势打开。

## 调整设置

你可以通过 `NVDA 菜单 → 首选项 → 设置 → WordBridge` 调整以下选项：

- **服务提供商**\
  选择提供文字纠错服务的云服务提供商。

- **大型语言模型（LLM）**\
  根据所选的服务提供商，选择合适的语言模型。

- **纠错模式**\
  - *标准模式*：纠错结果的读音会尽量接近原文，适合希望避免联想到关联较弱的同音字的用户。\
  - *轻量模式*：纠错结果的读音可能与原文有较大差异，适合希望在输入时探索更多同音字联想的用户。

- **简体／繁体中文**\
  指定待处理的文字使用简体中文还是繁体中文。输入文字会自动转换为所选的简体或繁体形式。

- **个人词典**\
  提供自定义词汇列表，以提高专业领域词汇或专业术语的纠错准确率。你可以从设置中打开“编辑词典”添加词汇。检查文字时，WordBridge 会将这些词汇发送给 LLM 作为参考。

---

## Coseeing 服务

Coseeing 提供有使用频率限制的免费额度，适合短期试用功能。如果需要大量使用，建议在受支持的服务提供商处注册并获取自己的 API 密钥，以获得更快、更稳定的服务。

---

## 数据隐私

执行文字检查时，选中的文字会发送给你设置的 **服务提供商** 进行处理。使用前请阅读所选服务提供商的隐私政策。
