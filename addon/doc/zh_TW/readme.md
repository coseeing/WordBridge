# WordBridge 使用指南

WordBridge 是一款結合 AI 的 NVDA 附加元件，協助使用者辨識並修正中文同音錯字。

每次檢查後，WordBridge 會產生修正報告，呈現原始文字、建議修正文字，以及相關字詞說明。使用者可以藉此核對用字，並在校對過程中學習詞彙、累積正確的用字經驗，逐步提升文字書寫能力。

## 執行文字檢查

要檢查文字是否有同音錯字，請先選取要檢查的內容，然後按下 `NVDA+Alt+O`。檢查期間會播放提示音效。檢查完成後，修正後的文字會自動複製到剪貼簿，方便後續使用。

---

## 檢視修正報告

每次執行文字檢查時，WordBridge 都會產生一份報告，列出所有辨識出的錯字。每個錯字都會以可點擊的按鈕呈現，點擊後可查看原始文字與修正文字的字詞解釋，幫助使用者在每次校對的過程中學習詞彙、累積正確的用字經驗，提升文字書寫能力。

若已啟用 **「自動顯示修正報告」** 選項，報告頁面會在每次檢查後自動開啟。若未啟用，也可以隨時按下 **「顯示修正報告」** 手勢來開啟。

## 調整設定

您可以透過 `NVDA 功能表 → 偏好設定 → 設定 → WordBridge` 調整下列選項：

- **服務供應商**\
  選擇提供文字修正服務的雲端服務供應商。

- **大型語言模型（LLM）**\
  根據所選的服務供應商，選擇適用的語言模型。

- **修正模式**\
  - *標準模式*：修正結果的發音會盡量貼近原文，適合希望避免擴大聯想至關聯較弱同音字的使用者。\
  - *輕量模式*：修正結果的發音可能與原文差異較大，適合希望在輸入情境中探索更多同音聯想的使用者。

- **簡體／繁體中文**\
  指定要處理的文字屬於簡體中文或繁體中文。輸入文字會自動轉換為所選字體。

- **個人化詞典**\
  提供自訂詞彙清單，以提升領域專用詞彙或專業術語的修正準確度。您可從設定中開啟編輯辭典新增詞彙。檢查文字時，WordBridge 會將這些詞彙傳給 LLM 作為參考。

## Coseeing 服務

Coseeing 提供限流免費額度，適合短期體驗功能，如有大量使用需求，建議自行至所支援的服務供應商註冊取得 API key，以獲得更快速且穩定的服務。

---

## 資料隱私

執行文字檢查時，所選文字會傳送至您所設定的 **服務供應商** 進行處理。請在使用前詳閱所選服務供應商的隱私權政策。
