> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the three P0 findings shared by `review-claude-2.md` (T1–T3) and `review-codex-2.md` (R01–R03): report script/HTML injection, shutdown blocking plus cross-thread `latest_action`, and — as a spike only — vendored dependency isolation.

R03 ships a standalone probe script only — no product code.

**Tech Stack:** Python 3.11+ (NVDA runtime is CPython 3.13 x64), pytest, wxPython (stubbed in tests), Vue 3 and SweetAlert2 in the report template.

def _inline_config(html):
	"""Return the JSON text assigned to window.contentConfig."""
	assignment = html.split("window.contentConfig = ", 1)[1]
	return assignment.split(";", 1)[0]

```python
# json.dumps does not encode these, so a "</script>" sequence inside the
# selected text or the model output would terminate the inline script element.
# All five are valid JSON string escapes, so JSON.parse returns the original
# value unchanged.
JS_STRING_ESCAPES = {
	"<": "\\u003c",
	">": "\\u003e",
	"&": "\\u0026",
	"\u2028": "\\u2028",
	"\u2029": "\\u2029",
}


def _escape_for_inline_script(serialized: str) -> str:
	for character, escape in JS_STRING_ESCAPES.items():
		serialized = serialized.replace(character, escape)
	return serialized
```

Then change the substitution at the end of `text2template()` from:

```python
	content = template.replace(
		CONTENT_CONFIG_PLACEHOLDER,
		json.dumps(content_config, ensure_ascii=False),
	)
```

to:

```python
	content = template.replace(
		CONTENT_CONFIG_PLACEHOLDER,
		_escape_for_inline_script(json.dumps(content_config, ensure_ascii=False)),
	)
```

Leave the two character-reference `re.sub` calls above it untouched — they must keep running *before* the escaping, which is what `test_numeric_character_reference_is_decoded_then_escaped` pins down.
